# 通用模块注册脚本使用说明

## 功能

这是一个通用的自定义模块动态注册脚本，可以：
- ✅ 自动扫描指定目录下的所有Python模块
- ✅ 动态注册到ultralytics，**无需修改源码**
- ✅ 支持多个模块目录
- ✅ 自动处理导入错误
- ✅ 可复用于所有后续改进

## 使用方法

### 方法1：在训练脚本中使用（推荐）

```python
# 在导入YOLO之前注册模块
from scripts.register_custom_modules import register_modules

# 注册单个目录
register_modules('models/CBAM')

# 或注册多个目录
register_modules('models/CBAM', 'models/Transformer', 'models/Attention')

# 然后正常使用YOLO
from ultralytics import YOLO
model = YOLO("models/CBAM/baseline_CBAM.yaml")
```

## 工作原理

1. **自动扫描**：扫描指定目录下的所有`.py`文件
2. **动态导入**：使用`importlib`动态导入模块
3. **类提取**：提取模块中所有大写开头的类
4. **注册到ultralytics**：将类添加到`ultralytics.nn.tasks`命名空间
5. **YAML解析**：ultralytics解析yaml时能找到这些类

## 添加新模块的步骤

### 步骤1：创建新模块目录

```bash
mkdir test/models/NewModule
```

### 步骤2：编写模块代码

```python
# test/models/NewModule/my_module.py
import torch.nn as nn

class MyCustomModule(nn.Module):
    def __init__(self, channels):
        super().__init__()
        # 你的实现
        
    def forward(self, x):
        # 你的实现
        return x
```

### 步骤3：在训练脚本中注册

```python
from scripts.register_custom_modules import register_modules

# 注册新模块
register_modules('models/NewModule')

from ultralytics import YOLO
model = YOLO("models/NewModule/config.yaml")
```

### 步骤4：在yaml中使用

```yaml
backbone:
  - [-1, 1, MyCustomModule, [256]]  # 直接使用
```

## 注意事项

### ✅ 可以做的

- 在一个目录放多个模块文件
- 一个文件定义多个类
- 注册多个目录
- 模块之间相互导入

### ❌ 不要做的

- 不要修改ultralytics源码
- 不要在模块文件名中使用`__init__`或`register`
- 不要在类名前加下划线（会被忽略）

## 常见问题

### Q1: 模块注册失败？

**检查**：
1. 模块文件是否在正确的目录
2. 类名是否以大写字母开头
3. 是否在导入YOLO之前注册

### Q2: yaml解析找不到模块？

**检查**：
1. 注册脚本是否成功执行（看输出）
2. yaml中的模块名是否与类名完全一致
3. 是否在正确的目录运行训练脚本

### Q3: 如何验证模块已注册？

```python
from scripts.register_custom_modules import register_modules, list_registered_modules

register_modules('models/CBAM')
list_registered_modules()  # 列出所有已注册的模块
```
